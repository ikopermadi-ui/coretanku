    Gambar tangan sendiri

    Tangan bawaan memakai file tangan.png. Kalau mau mengganti, pakai PNG berlatar transparan dan tanpa watermark, karena apa pun yang ada di gambar ikut tampil di video. Tangan sebaiknya masuk dari kanan dengan ujung pena mengarah ke kiri bawah.

    Klik tepat di ujung pena atau pensil pada pratinjau ini. Titik merah menandai tempat tangan menggambar.

    Buat gambar dengan AI (Gemini)

    Cara ini memakai kuota chat Gemini-mu (gemini.google.com), bukan token API. Browser tidak mengizinkan app ini mengirim prompt atau mengambil gambar dari chat Gemini secara otomatis, jadi langkahnya: 1) salin prompt, 2) buka Gemini, tempel, dan tunggu gambarnya jadi, 3) salin gambar hasilnya (klik kanan → Salin gambar), lalu kembali ke sini dan tekan Ctrl+V.

    Tulis prompt di kolom di atas, satu baris untuk satu gambar. Barisnya muncul di sini dengan tombol Salin.

    Buka Gemini ↗
    Tempel gambar hasil Gemini di sini (Ctrl+V) atau seret file gambar ke kotak ini

    Gambar dari Gemini memakai latar yang mengikuti prompt. Prompt yang disalin sudah meminta latar putih polos, supaya cocok untuk efek sketsa dan stiker.

    Kunci API Gemini

    Belum ada kunci. Buat di Google AI Studio (aistudio.google.com), lalu tempel di sini. Kunci dikirim langsung dari browsermu ke Google, tidak lewat server lain.

    Kuota API terpisah dari kuota aplikasi Gemini, dan tiap model gambar punya kuota sendiri. Kalau satu model habis, ganti model di kolom di atas. Pembuatan gambar dihitung per gambar oleh Google (cek harga dan kuota terbaru di Google AI Studio). Kunci terlihat di browser, jadi batasi kunci ke alamat situsmu di pengaturan Google Cloud dan jangan pakai di komputer umum.
